## Features
- Lessons loaded from the back end with fetch
- Search by subject, location, price or spaces
- Sort by subject, location, price or spaces, ascending or descending
- Filter lessons by teacher, with the teacher's name shown on each lesson and in the cart
- Shopping cart with live space counts
- Checkout with name(letters only) and phone(numbers only) validation
- Orders saved to the database and lesson spaces updated after checkout
